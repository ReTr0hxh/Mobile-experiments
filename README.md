# 📱 Mobile Experiments (React Native)

Bem-vindo ao meu laboratório de desenvolvimento mobile! 🚀

Este repositório é um **monorepo** onde guardo meus mini-projetos, desafios e experimentos construídos com **React Native**. A ideia principal aqui é aplicar o aprendizado "Just-in-Time": dominar novos conceitos lógicos e ferramentas na prática, construindo aplicações funcionais e resolvendo problemas reais.

---

## 📂 Índice de Projetos

Aqui estão os aplicativos desenvolvidos e os que estão no meu radar para o futuro:

* ✅ **[FocusFlow](./FocusFlow)** - Um assistente de produtividade baseado na técnica Pomodoro com consumo de API externa (*AdviceSlip API*).
* ⏳ **CâmbioNow** *(Em breve)* - Conversor de moedas em tempo real utilizando consumo de APIs financeiras e armazenamento de histórico (`AsyncStorage`).
* ⏳ **MoodTracker** *(Em breve)* - Diário de humor e bem-estar para treinar manipulação de datas e entradas de dados complexas.
* ⏳ **WikiDex** *(Em breve)* - Explorador de APIs públicas com renderização de listas avançadas e rolagem infinita.

---

## 🛠️ Tecnologias Utilizadas

Ao longo destes projetos, exploro e aprofundo conhecimentos em:

* **React Native** (Expo)
* **JavaScript** (ES6+)
* **Gerenciamento de Estado** (`useState`, `useEffect`)
* **Consumo de APIs** (`fetch`, `async/await`)
* **Navegação e Estruturação de UI/UX**

## 🚀 Como testar os projetos

Como este é um monorepo, cada projeto possui suas próprias dependências. Para rodar qualquer um deles, siga os passos abaixo:

1. Clone este repositório:
```bash
git clone [https://github.com/ReTr0hxh/Mobile-experiments.git](https://github.com/ReTr0hxh/Mobile-experiments.git)
```

2. Pelo terminal, acesse a pasta do projeto que deseja testar. Exemplo:
```bash
cd FocusFlow
```

3. Instale as dependências do projeto específico:
```bash
npm install
```

4. Inicie o servidor do Expo:
```bash
npx expo start
```
